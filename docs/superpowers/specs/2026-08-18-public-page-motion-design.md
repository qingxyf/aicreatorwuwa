# 公开活动页动效设计

## 目标

为公开活动首页补齐下半页的前端动效，让规则、投稿、盲选、投票和奖励区域在滚动浏览时有清晰的节奏，同时保持作品投票的可读性、可操作性和低干扰。

## 设计原则

- 使用现有 React + CSS 体系，不新增动画库或外部资源。
- 动效只强化层级和反馈，不改变信息顺序、文案、投票规则或接口行为。
- 所有持续动画保持低幅度；投票区域优先保证作品、作者和按钮清晰。
- 当浏览器不支持 `IntersectionObserver` 或用户启用 `prefers-reduced-motion` 时，内容直接显示并保留必要的状态变化。

## 动效范围

### 滚动显现

公开首页根节点启用轻量观察器，观察带有 `data-reveal` 标记的已有区块。元素首次进入视口后增加已显现状态，并保持该状态。区块按层级采用淡入和 16–24px 上移，卡片组使用 60–90ms 错峰延迟。

覆盖：规则区、投稿提示、盲选面板、投票展廊、奖励区，以及规则卡片、投票规则卡片和奖励卡片。

### 阶段与内容反馈

- 活动阶段时间轴进入视口时绘制连接线；当前阶段使用低亮度呼吸光，不改变文字颜色对比度。
- 盲选卡片 hover 时轻微抬升，媒体区域做低幅缩放；点击后继续使用现有状态提示，不增加额外阻塞层。
- 投票卡片 hover 时轻微抬升；投票成功后现有“今日已投”按钮触发一次确认脉冲。
- 奖励卡片按顺序错峰进入，边框装饰线只做一次性显现。
- 角色组保留现有漂浮动画，其他持续动画不叠加在作品媒体上。

## 实现边界

- 在 `App` 组合层管理观察器生命周期和显现状态，不把业务规则移入样式或动画代码。
- 使用 CSS keyframes、transition 和 `animation-delay`；媒体仍使用 `object-fit: contain` 的完整展示策略。
- 动效类名使用页面范围前缀，避免影响 `/ops` 后台页面和 Ant Design 全局组件。
- 不新增 provider、存储、接口或数据库字段。

## 验证标准

- 桌面端首屏加载无空白，滚动到各区块时显现一次且不反复闪烁。
- 盲选卡片和投票按钮仍可点击，投票成功状态可见。
- 390px 移动端无横向溢出，作品与阶段时间轴可读。
- 减少动态效果模式下不隐藏内容、不产生位移或持续闪烁。
- 运行 `npm run check:precompletion`，并通过浏览器检查页面身份、控制台、截图和目标交互。
